# Автодневник

iOS-приложение для ведения дневника автомобилиста: история ТО и ремонтов и напоминания о регламентных работах.

## Возможности

**Журнал ТО и ремонтов**
- записи с датой, пробегом, категорией (ТО, ремонт, шины, диагностика, кузов, другое), сервисом и заметками;
- список запчастей и материалов с артикулом, количеством и ценой, автоматический подсчёт итоговой стоимости;
- группировка по месяцам, поиск по работам, запчастям и сервису, фильтр по категории;
- расходы за текущий год.

**Напоминания**
- по дате, по пробегу или по тому, что наступит раньше;
- повтор через заданное число километров и/или месяцев;
- типовые работы в один тап: масло, фильтры, тормозная жидкость, свечи, ГРМ, шины, ОСАГО, техосмотр;
- статусы «Просрочено / Скоро / Запланировано» и счётчик на вкладке;
- «Выполнено» добавляет запись в журнал и переносит срок на следующий цикл;
- локальные уведомления за неделю и в день срока.

**Гараж**: несколько автомобилей, быстрое переключение между ними.

Все данные хранятся на устройстве (SwiftData).

## Требования

- Xcode 16 или новее
- iOS 17.0+

## Запуск

1. Откройте `AutoDiary.xcodeproj` в Xcode.
2. Выберите симулятор iPhone или подключённый iPhone.
3. Для запуска на своём телефоне укажите команду разработчика: target **AutoDiary** → **Signing & Capabilities** → **Team** (подойдёт бесплатный Apple ID).
4. Нажмите ⌘R.

## Структура

```
AutoDiary/
├── AutoDiaryApp.swift          точка входа, контейнер SwiftData
├── Models/                     Car, ServiceRecord, Part, Reminder, шаблоны работ
├── Services/                   локальные уведомления
├── Utilities/                  форматирование чисел, дат, склонения
├── Views/
│   ├── Journal/                журнал, карточка записи, форма записи
│   ├── Reminders/              список, форма, отметка о выполнении
│   ├── Garage/                 автомобили
│   └── Components/             общие элементы и поля ввода чисел
└── Preview/                    тестовые данные для превью Xcode
```
